03 · Cómo se guardan los datos

usuarios
  UID_DEL_ESTUDIANTE
    sesiones
      ID_AUTOMATICO
        curso: "Servicios y Aplicaciones para IoT"
        fecha: Timestamp
        horasDedicadas: 1.5
        tipoActividad: "Laboratorio"

UID es el identificador que entrega Firebase Authentication a cada usuario. Dos estudiantes pueden guardar sesiones con el mismo curso sin compartir datos.

Un documento es una sesión. Firestore genera el ID al crearla. Ese ID se toma del documento para editar o eliminar; no necesitamos guardarlo dentro de sus campos.

El modelo tiene constructor vacío, getters y setters para que toObject(Sesion.class) convierta cada documento en un objeto Java. La fecha se representa con Date y Firestore la almacena como Timestamp.

La separación en el código ayuda a consultar la ruta correcta. La protección real la aplican las reglas del servidor: publica firestore.rules en Firebase antes de probar con varios usuarios.

04 · Acceso sin programar todo desde cero

  1. El inicio comprueba FirebaseAuth.getInstance().getCurrentUser(). Si existe, entra a la lista.
  2. El botón de acceso abre FirebaseUI con correo y Google. auth_personalizado.xml define el logo, los textos y ambos botones.
  3. FirebaseUI se encarga de las pantallas de correo, contraseña, registro y recuperación. Se desactiva la búsqueda automática de credenciales guardadas para abrir directamente los botones de correo y Google. La app se configura en español.
  4. El resultado vuelve al ActivityResultLauncher. Se entra solo si el resultado fue correcto y existe un usuario.
  5. Al cerrar sesión se usa AuthUI.signOut() y se limpia la pila de pantallas para que Atrás no vuelva a los datos.

Además, el inicio ofrece Recuperar contraseña: valida un correo y usa sendPasswordResetEmail(). El mensaje no revela si el correo está registrado. Para usuarios que solo acceden con Google, la recuperación se realiza en su cuenta Google.

Se retiró Facebook porque el laboratorio solicita correo y Google.

05 · Entender el registro, listado, edición y borrado

Registrar

El formulario comienza con la fecha de hoy. Se selecciona el curso, las horas, el tipo y la fecha con un calendario. Antes de guardar se comprueba que el curso no esté vacío y que las horas sean mayores que 0 y como máximo 24. Esta última condición es una validación añadida para una sesión de un día.

Se aceptan decimales: tanto 1.5 como 1,5 se convierten a un número. El curso admite hasta 100 caracteres.

Map<String, Object> datos = new HashMap<>();
datos.put("curso", curso);
datos.put("fecha", fecha.getTime());
datos.put("horasDedicadas", horas);
datos.put("tipoActividad", tipo);
misSesiones().add(datos);

Esquema simplificado del guardado. El código completo añade validaciones y maneja el resultado.

Listar en tiempo real

addSnapshotListener() entrega la lista inicial y vuelve a ejecutarse cuando cambia un documento. El callback vacía las listas en memoria, agrega los documentos actuales y llama a notifyDataSetChanged(). La consulta ordena por fecha descendente. El listener se quita en onStop() y vuelve a crearse en onStart().

Editar con el mismo formulario

Desde la lista se envía el extra sesionId. Si existe, se carga el documento y se rellenan los campos. Si no existe, el formulario crea una nueva sesión.

// Sin ID: crear. Con ID: actualizar el documento existente.
Task<?> tarea = sesionId == null
        ? misSesiones().add(datos)
        : misSesiones().document(sesionId).update(datos);

update() evita recrear por accidente una sesión que haya sido eliminada desde otro dispositivo.

Eliminar

Se pide confirmar y se ejecuta misSesiones().document(id).delete(). No hay que borrar manualmente la fila: el listener recibe el cambio y actualiza la lista.

Escribir sin que la barra tape el formulario

Las pantallas de entrada usan adjustResize. La app reserva los márgenes de las barras del sistema y del teclado una sola vez. Mientras el teclado está abierto se oculta la navegación inferior; al cerrarlo reaparece. El formulario permanece dentro de un ScrollView para acceder a los campos y botones en pantallas pequeñas.

Operaciones asíncronas

Firebase responde después de iniciar una operación. Por eso se utilizan callbacks como addOnCompleteListener(). Durante la carga o el guardado se deshabilitan controles y se muestra un mensaje; si falla se informa al usuario.

06 · Los gráficos: filtrar y sumar

La parte importante está en ResumenEstudio.calcular(). Su lógica es un único recorrido:

  1. Si se eligió un curso y la sesión pertenece a otro, saltarla.
  2. Obtener una clave de mes en formato yyyy-MM.
  3. Sumar sus horas al mes correspondiente.
  4. Sumar esas mismas horas al tipo de actividad.
String mes = formato.format(sesion.getFecha());
resumen.porMes.put(mes,
        resumen.porMes.getOrDefault(mes, 0.0) + horas);
resumen.porTipo[tipo] += horas;
resumen.total += horas;

El mapa de meses es un TreeMap, así que quedan en orden cronológico. Usar año y mes evita mezclar noviembre de 2025 con noviembre de 2026. Se muestran los meses que tienen sesiones.

EjemploCursoMesTipoHoras
1IoT10/2026Teoría1.5
2IoT10/2026Laboratorio2
3Redes11/2026Práctica3

Con Todos los cursos: octubre suma 3.5 h y noviembre 3 h. Al filtrar IoT, queda octubre con 3.5 h; la torta muestra Teoría ≈ 42.86% y Laboratorio ≈ 57.14%.

GraficoView convierte estos resultados a formas: drawRect() dibuja cada barra y drawArc() dibuja las porciones de la torta.

largoBarra = horasDelMes / maximoMensual * anchoDisponible;
anguloPorcion = horasDelTipo / totalHoras * 360;
porcentaje = horasDelTipo / totalHoras * 100;

Si el total es cero se muestra Sin datos para graficar y no se divide entre cero. El mismo filtro alimenta ambos gráficos, y sus datos también se actualizan en tiempo real.

07 · Lo que debes comprobar en Firebase

Configuración externa pendiente de verificar. El proyecto incluye tu google-services.json. No se ha entrado a tu consola ni publicado reglas desde esta tarea. La compilación no confirma que los proveedores estén habilitados o que los permisos del servidor sean correctos.
  1. Abre el proyecto correspondiente a tu JSON en Firebase Console.
  2. En Authentication → Métodos de acceso habilita Correo/contraseña y Google. Configura el correo de soporte si se solicita.
  3. En Configuración del proyecto → Tu app Android verifica com.example.lab6. Registra SHA-1 y SHA-256 de la clave de depuración de cada computadora en la que ejecutarás la app. Puedes obtenerlas con gradlew.bat :app:signingReport.
  4. Después de habilitar Google o añadir certificados, descarga de nuevo google-services.json y reemplaza el archivo en app/. El JSON actual contiene un cliente web OAuth; eso no confirma que estén registradas las claves de cada equipo.
  5. Crea Cloud Firestore si todavía no existe, entra en Reglas, pega el contenido de firestore.rules y publícalo. No hace falta crear documentos o índices compuestos manualmente.
  6. Prueba con dos cuentas diferentes: una no debe leer ni modificar las sesiones de la otra.

El enunciado también solicita compartir el proyecto Firebase con la docente y entregar un repositorio público con el nombre indicado. Haz esos pasos desde tus cuentas; esta tarea no envió invitaciones ni publicó el repositorio.

Qué permiten las reglas

Leer y eliminar requiere que el UID del usuario coincida con el UID de la ruta. Crear y actualizar exige, además, los cuatro campos correctos, fecha Timestamp, horas entre 0 y 24 sin incluir cero y un tipo de actividad permitido. Las demás rutas quedan denegadas si publicas este archivo como las reglas completas del proyecto.

08 · Guía de prueba para el laboratorio

  1. Sin usuario: comprueba logo y textos en español. Registra una cuenta con correo y cierra sesión.
  2. Inicia sesión con la misma cuenta. Cierra y vuelve a abrir la app: debe entrar directamente a Mis sesiones.
  3. Prueba Recuperar contraseña con un correo propio y revisa el enlace recibido.
  4. Prueba Google. Si falla, revisa proveedor habilitado, SHA del equipo, JSON actualizado y conexión.
  5. Crea las tres sesiones del ejemplo anterior. Prueba también curso vacío, horas vacías, 0 y 25: no deben guardarse.
  6. Toca una sesión → Editar. Cambia horas, curso, fecha y tipo; comprueba que se actualice la misma sesión.
  7. Toca una sesión → Eliminar. Primero cancela y comprueba que siga; luego confirma.
  8. Abre la misma cuenta en otro dispositivo y cambia datos: comprueba que lista y gráficos se actualicen.
  9. Ve a Estadísticas, verifica totales y filtra IoT. Ambos gráficos deben cambiar juntos.
  10. Prueba meses iguales en años distintos, un curso sin sesiones y una cuenta completamente nueva.
  11. Cierra sesión y entra con otra cuenta: no debe aparecer la información anterior. Prueba también el simulador de reglas con UID diferente: lectura y escritura deben ser denegadas.

package com.example.lab6;
import android.content.Intent;
import android.os.Bundle;
import android.text.InputType;
import android.util.Patterns;
import android.widget.EditText;
import androidx.activity.result.ActivityResultLauncher;
import androidx.appcompat.app.AlertDialog;
import androidx.appcompat.app.AppCompatActivity;
import androidx.appcompat.app.AppCompatDelegate;
import androidx.core.os.LocaleListCompat;
import com.example.lab6.databinding.ActivityMainBinding;
import com.firebase.ui.auth.AuthMethodPickerLayout;
import com.firebase.ui.auth.AuthUI;
import com.firebase.ui.auth.FirebaseAuthUIActivityResultContract;
import com.google.firebase.auth.FirebaseAuth;
import java.util.Arrays;

public class MainActivity extends AppCompatActivity {
    private ActivityMainBinding binding;
    private boolean entrando;
    private final ActivityResultLauncher<Intent> launcher = registerForActivityResult(
            new FirebaseAuthUIActivityResultContract(), result -> {
                binding.btnAcceder.setEnabled(true);
                if (result.getResultCode() == RESULT_OK && FirebaseAuth.getInstance().getCurrentUser() != null) entrar();
                else binding.tvMensaje.setText("Acceso cancelado o no completado. Revisa tu conexión y Firebase.");
            });
    @Override protected void onCreate(Bundle state) {
        super.onCreate(state);
        AppCompatDelegate.setApplicationLocales(LocaleListCompat.forLanguageTags("es"));
        binding = ActivityMainBinding.inflate(getLayoutInflater());
        setContentView(binding.getRoot());
        PantallaBase.aplicarMargenes(this, binding.getRoot());
        FirebaseAuth.getInstance().setLanguageCode("es");
        binding.btnAcceder.setOnClickListener(v -> acceder());
        binding.btnRecuperar.setOnClickListener(v -> recuperar());
    }
    @Override protected void onStart() {
        super.onStart();
        if (FirebaseAuth.getInstance().getCurrentUser() != null) entrar();
    }
    private void acceder() {
        try {
            AuthMethodPickerLayout layout = new AuthMethodPickerLayout.Builder(R.layout.auth_personalizado)
                    .setEmailButtonId(R.id.btnCorreo).setGoogleButtonId(R.id.btnGoogle).build();
            Intent intent = AuthUI.getInstance().createSignInIntentBuilder()
                    .setAvailableProviders(Arrays.asList(new AuthUI.IdpConfig.EmailBuilder().build(),
                            new AuthUI.IdpConfig.GoogleBuilder().build()))
                    .setAuthMethodPickerLayout(layout).setLogo(R.drawable.pucp)
                    // Mostrar siempre los botones, sin buscar credenciales guardadas al abrir.
                    .setTheme(R.style.Theme_Acceso).setCredentialManagerEnabled(false).build();
            binding.btnAcceder.setEnabled(false);
            launcher.launch(intent);
        } catch (Exception e) {
            binding.btnAcceder.setEnabled(true);
            binding.tvMensaje.setText("No se pudo abrir el acceso. Comprueba Google en Firebase y google-services.json.");
            android.util.Log.e("Acceso", "No se pudo iniciar FirebaseUI", e);
        }
    }
    private void recuperar() {
        EditText correo = new EditText(this);
        correo.setHint("Correo electrónico");
        correo.setInputType(InputType.TYPE_CLASS_TEXT | InputType.TYPE_TEXT_VARIATION_EMAIL_ADDRESS);
        AlertDialog dialog = new AlertDialog.Builder(this).setTitle("Recuperar contraseña")
                .setView(correo).setNegativeButton("Cancelar", null)
                .setPositiveButton("Enviar enlace", null).create();
        dialog.setOnShowListener(d -> dialog.getButton(AlertDialog.BUTTON_POSITIVE).setOnClickListener(v -> {
            String email = correo.getText().toString().trim();
            if (!Patterns.EMAIL_ADDRESS.matcher(email).matches()) {
                correo.setError("Ingresa un correo válido"); return;
            }
            dialog.getButton(AlertDialog.BUTTON_POSITIVE).setEnabled(false);
            FirebaseAuth.getInstance().sendPasswordResetEmail(email).addOnCompleteListener(task -> {
                dialog.getButton(AlertDialog.BUTTON_POSITIVE).setEnabled(true);
                if (task.isSuccessful()) {
                    binding.tvMensaje.setText("Si el correo tiene una cuenta con contraseña, recibirás un enlace. Revisa también spam.");
                    dialog.dismiss();
                } else correo.setError("No se pudo enviar. Revisa tu conexión e inténtalo nuevamente.");
            });
        }));
        dialog.show();
    }
    private void entrar() {
        if (entrando) return;
        entrando = true;
        startActivity(new Intent(this, SesionesActivity.class)
                .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK));
        finish();
    }
}

package com.example.lab6;
import android.content.Intent;
import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Toast;
import androidx.appcompat.app.AlertDialog;
import com.example.lab6.databinding.ActivitySesionesBinding;
import com.google.firebase.firestore.DocumentSnapshot;
import com.google.firebase.firestore.ListenerRegistration;
import com.google.firebase.firestore.Query;
import java.text.SimpleDateFormat;
import java.util.ArrayList;
import java.util.Locale;

public class SesionesActivity extends PantallaBase {
    private ActivitySesionesBinding binding;
    private final ArrayList<Sesion> sesiones = new ArrayList<>();
    private final ArrayList<String> filas = new ArrayList<>();
    private ArrayAdapter<String> adapter;
    private ListenerRegistration escucha;
    private boolean borrando;
    @Override protected void onCreate(Bundle state) {
        super.onCreate(state);
        binding = ActivitySesionesBinding.inflate(getLayoutInflater());
        setContentView(binding.getRoot());
        aplicarMargenes(this, binding.getRoot());
        prepararNavegacion(binding.navegacion, R.id.navSesiones);
        adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, filas);
        binding.listaSesiones.setAdapter(adapter);
        binding.listaSesiones.setEmptyView(binding.tvVacio);
        binding.btnNuevo.setOnClickListener(v -> startActivity(new Intent(this, FormSesionActivity.class)));
        binding.listaSesiones.setOnItemClickListener((parent, view, posicion, id) -> {
            if (borrando) return;
            Sesion sesion = sesiones.get(posicion);
            new AlertDialog.Builder(this).setTitle(sesion.getCurso())
                    .setItems(new String[]{"Editar", "Eliminar"}, (dialog, opcion) -> {
                        if (opcion == 0) {
                            startActivity(new Intent(this, FormSesionActivity.class).putExtra("sesionId", sesion.getId()));
                        } else {
                            new AlertDialog.Builder(this).setTitle("Eliminar sesión")
                                    .setMessage("¿Eliminar esta sesión definitivamente?")
                                    .setNegativeButton("Cancelar", null)
                                    .setPositiveButton("Eliminar", (d, b) -> eliminar(sesion)).show();
                        }
                    }).show();
        });
    }
    @Override protected void onStart() {
        super.onStart();
        if (!comprobarUsuario()) return;
        escucha = misSesiones().orderBy("fecha", Query.Direction.DESCENDING).addSnapshotListener((datos, error) -> {
            if (error != null) {
                binding.tvResumen.setText("No se pudieron cargar las sesiones.");
                binding.tvVacio.setText("Revisa la conexión y las reglas de Cloud Firestore.");
                return;
            }
            sesiones.clear(); filas.clear();
            double total = 0;
            SimpleDateFormat formato = new SimpleDateFormat("dd/MM/yyyy", new Locale("es", "PE"));
            if (datos != null) for (DocumentSnapshot documento : datos.getDocuments()) {
                Sesion sesion = documento.toObject(Sesion.class);
                if (sesion == null || sesion.getFecha() == null || sesion.getHorasDedicadas() == null) continue;
                sesion.setId(documento.getId());
                sesiones.add(sesion);
                total += sesion.getHorasDedicadas();
                filas.add(sesion.getCurso() + "\n" + formato.format(sesion.getFecha()) + " · "
                        + sesion.getHorasDedicadas() + " h\n" + sesion.getTipoActividad());
            }
            adapter.notifyDataSetChanged();
            binding.tvResumen.setText(String.format(new Locale("es", "PE"), "%d sesiones · %.2f horas\nToca una sesión para editarla o eliminarla.", sesiones.size(), total));
            binding.tvVacio.setText("Aún no tienes sesiones. Pulsa Nueva sesión para comenzar.");
        });
    }
    private void eliminar(Sesion sesion) {
        if (!comprobarUsuario() || borrando) return;
        borrando = true;
        misSesiones().document(sesion.getId()).delete().addOnCompleteListener(task -> {
            borrando = false;
            Toast.makeText(this, task.isSuccessful() ? "Sesión eliminada" : "No se pudo eliminar. Revisa tu conexión y permisos.", Toast.LENGTH_LONG).show();
        });
    }
    @Override protected void onStop() {
        super.onStop();
        if (escucha != null) { escucha.remove(); escucha = null; }
    }
}

package com.example.lab6;
import android.app.DatePickerDialog;
import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Toast;
import com.example.lab6.databinding.ActivityFormSesionBinding;
import com.google.android.gms.tasks.Task;

import java.util.Arrays;
import java.util.Calendar;
import java.util.HashMap;
import java.util.Locale;
import java.util.Map;

public class FormSesionActivity extends PantallaBase {
    private ActivityFormSesionBinding binding;
    private final Calendar fecha = Calendar.getInstance();
    private String sesionId;
    private boolean ocupado;
    private boolean cargado;
    private final String[] tipos = {"Teoría", "Práctica", "Laboratorio"};
    @Override protected void onCreate(Bundle state) {
        super.onCreate(state);
        binding = ActivityFormSesionBinding.inflate(getLayoutInflater());
        setContentView(binding.getRoot());
        aplicarMargenes(this, binding.getRoot());
        prepararNavegacion(binding.navegacion, R.id.navSesiones);
        ArrayAdapter<String> adapter = new ArrayAdapter<>(this, android.R.layout.simple_spinner_item, tipos);
        adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item);
        binding.spTipoActividad.setAdapter(adapter);
        sesionId = getIntent().getStringExtra("sesionId");
        cargado = sesionId == null || (state != null && state.getBoolean("cargado"));
        fecha.set(Calendar.HOUR_OF_DAY, 0); fecha.set(Calendar.MINUTE, 0);
        fecha.set(Calendar.SECOND, 0); fecha.set(Calendar.MILLISECOND, 0);
        if (state != null) fecha.setTimeInMillis(state.getLong("fecha"));
        mostrarFecha();
        binding.btnFecha.setOnClickListener(v -> new DatePickerDialog(this, (picker, year, month, day) -> {
            fecha.set(year, month, day); mostrarFecha();
        }, fecha.get(Calendar.YEAR), fecha.get(Calendar.MONTH), fecha.get(Calendar.DAY_OF_MONTH)).show());
        binding.btnGuardar.setOnClickListener(v -> guardar());
        binding.btnCancelar.setOnClickListener(v -> finish());
        if (!comprobarUsuario()) return;
        if (sesionId != null) {
            binding.tvTitulo.setText("Editar sesión de estudio");
            if (!cargado) cargar();
        }
    }
    @Override protected void onStart() { super.onStart(); comprobarUsuario(); }
    private void mostrarFecha() {
        binding.btnFecha.setText("Fecha: " + new SimpleDateFormat("dd/MM/yyyy", new Locale("es", "PE")).format(fecha.getTime()));
    }
    private void cargar() {
        habilitar(false);
        misSesiones().document(sesionId).get().addOnCompleteListener(task -> {
            if (isFinishing() || isDestroyed()) return;
            if (!task.isSuccessful()) {
                binding.tvAviso.setText("No se pudo cargar. Vuelve a la lista e inténtalo nuevamente."); return;
            }
            Sesion sesion = task.getResult().toObject(Sesion.class);
            if (sesion == null || sesion.getFecha() == null) {
                binding.tvAviso.setText("Esta sesión ya no existe o no tiene una fecha válida."); return;
            }
            binding.etCurso.setText(sesion.getCurso());
            binding.etHoras.setText(String.valueOf(sesion.getHorasDedicadas()));
            int posicion = Arrays.asList(tipos).indexOf(sesion.getTipoActividad());
            binding.spTipoActividad.setSelection(Math.max(0, posicion));
            fecha.setTime(sesion.getFecha()); mostrarFecha(); cargado = true; habilitar(true);
        });
    }
    private void guardar() {
        if (ocupado || !cargado || !comprobarUsuario()) return;
        String curso = binding.etCurso.getText().toString().trim();
        String textoHoras = binding.etHoras.getText().toString().trim().replace(',', '.');
        if (curso.isEmpty()) { binding.etCurso.setError("Escribe el nombre del curso"); return; }
        double horas;
        try { horas = Double.parseDouble(textoHoras); }
        catch (NumberFormatException e) { binding.etHoras.setError("Ingresa una cantidad válida, por ejemplo 1.5"); return; }
        if (!Double.isFinite(horas) || horas <= 0 || horas > 24) {
            binding.etHoras.setError("Las horas deben ser mayores que 0 y como máximo 24"); return;
        }
        Map<String, Object> datos = new HashMap<>();
        datos.put("curso", curso); datos.put("fecha", fecha.getTime());
        datos.put("horasDedicadas", horas);
        datos.put("tipoActividad", binding.spTipoActividad.getSelectedItem().toString());
        habilitar(false); binding.tvAviso.setText("Guardando sesión…");
        // add crea un documento; update modifica únicamente uno existente.
        Task<?> tarea = sesionId == null ? misSesiones().add(datos) : misSesiones().document(sesionId).update(datos);
        tarea.addOnCompleteListener(task -> {
            if (isFinishing() || isDestroyed()) return;
            if (task.isSuccessful()) {
                Toast.makeText(this, "Sesión guardada", Toast.LENGTH_SHORT).show(); finish();
            } else {
                habilitar(true);
                binding.tvAviso.setText("No se pudo guardar. Revisa la conexión y los permisos de Firestore.");
            }
        });
    }
    private void habilitar(boolean valor) {
        ocupado = !valor;
        binding.btnGuardar.setEnabled(valor); binding.etCurso.setEnabled(valor);
        binding.etHoras.setEnabled(valor); binding.spTipoActividad.setEnabled(valor);
        binding.btnFecha.setEnabled(valor);
        binding.navegacion.setEnabled(valor);
        androidx.core.view.ViewCompat.requestApplyInsets(binding.getRoot());
    }
    @Override protected void onSaveInstanceState(Bundle state) {
        state.putBoolean("cargado", cargado);
        state.putLong("fecha", fecha.getTimeInMillis()); super.onSaveInstanceState(state);
    }

package com.example.lab6;
import java.text.SimpleDateFormat;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.TreeMap;

// Cálculos independientes de Android: recorrer, filtrar y sumar.
public class ResumenEstudio {
    public final TreeMap<String, Double> porMes = new TreeMap<>();
    public final double[] porTipo = new double[3];
    public double total;
    public int cantidad;
    public static final String[] TIPOS = {"Teoría", "Práctica", "Laboratorio"};
    public static ResumenEstudio calcular(List<Sesion> sesiones, String curso) {
        ResumenEstudio resumen = new ResumenEstudio();
        SimpleDateFormat formato = new SimpleDateFormat("yyyy-MM", Locale.ROOT);
        for (Sesion sesion : sesiones) {
            if (curso != null && !curso.equals(sesion.getCurso())) continue;
            Double horas = sesion.getHorasDedicadas();
            if (sesion.getFecha() == null || horas == null || !Double.isFinite(horas) || horas <= 0) continue;
            int tipo = -1;
            for (int i = 0; i < TIPOS.length; i++) if (TIPOS[i].equals(sesion.getTipoActividad())) tipo = i;
            if (tipo == -1) continue;
            String mes = formato.format(sesion.getFecha());
            resumen.porMes.put(mes, resumen.porMes.getOrDefault(mes, 0.0) + horas);
            resumen.porTipo[tipo] += horas;
            resumen.total += horas;
            resumen.cantidad++;
        }
        return resumen;
    }
}

    public GraficoView(Context context, AttributeSet attrs) {
        super(context, attrs);
        android.content.res.TypedArray estilo = context.obtainStyledAttributes(new int[]{android.R.attr.textColorPrimary});

    private float dp(float n) { return n * getResources().getDisplayMetrics().density; }
    public void mostrar(ResumenEstudio resumen, boolean esTorta) {
        datos = resumen; torta = esTorta;
        StringBuilder descripcion = new StringBuilder(esTorta ? "Horas por actividad. " : "Horas por mes. ");
        if (esTorta) {
            for (int i = 0; i < 3; i++) descripcion.append(ResumenEstudio.TIPOS[i]).append(": ").append(datos.porTipo[i]).append(" horas. ");
        } else {
            for (Map.Entry<String, Double> mes : datos.porMes.entrySet()) descripcion.append(mes.getKey()).append(": ").append(mes.getValue()).append(" horas. ");
        }
        setContentDescription(descripcion.toString());

    }
    @Override protected void onMeasure(int widthSpec, int heightSpec) {
        int alto = (int) dp(torta ? 340 : Math.max(100, datos.porMes.size() * 46 + 25));
        setMeasuredDimension(resolveSize((int) dp(300), widthSpec), resolveSize(alto, heightSpec));
    }
    @Override protected void onDraw(Canvas canvas) {
        super.onDraw(canvas);
        if (datos.total == 0) { texto(canvas, "Sin datos para graficar", dp(12), dp(40)); return; }
        if (torta) dibujarTorta(canvas); else dibujarBarras(canvas);
    }
    private void texto(Canvas canvas, String texto, float x, float y) {
        pincel.setColor(colorTexto); pincel.setTextSize(dp(13));
        canvas.drawText(texto, x, y, pincel);
    }
    private String numero(double valor) { return String.format(new Locale("es", "PE"), "%.2f", valor); }
    private void dibujarBarras(Canvas canvas) {
        double maximo = 0;
        for (double valor : datos.porMes.values()) maximo = Math.max(maximo, valor);
        float inicio = dp(76), ancho = Math.max(dp(1), getWidth() - inicio - dp(85));
        int fila = 0;
        for (Map.Entry<String, Double> mes : datos.porMes.entrySet()) {
            float arriba = dp(12 + fila * 46);
            String clave = mes.getKey();
            texto(canvas, clave.substring(5) + "/" + clave.substring(0, 4), dp(4), arriba + dp(18));
            pincel.setColor(colores[0]);
            float largo = (float) (mes.getValue() / maximo * ancho);
            canvas.drawRect(inicio, arriba, inicio + largo, arriba + dp(26), pincel);
            texto(canvas, numero(mes.getValue()) + " h", inicio + largo + dp(6), arriba + dp(18));
            fila++;
        }
    }
    private void dibujarTorta(Canvas canvas) {
        float lado = Math.min(getWidth() - dp(24), dp(210));
        float izquierda = (getWidth() - lado) / 2;
        RectF circulo = new RectF(izquierda, dp(8), izquierda + lado, dp(8) + lado);
        float angulo = -90;
        for (int i = 0; i < 3; i++) {
            float porcion = (float) (datos.porTipo[i] / datos.total * 360);
            pincel.setColor(colores[i]);
            canvas.drawArc(circulo, angulo, porcion, true, pincel); angulo += porcion;
            float y = lado + dp(35 + i * 30);
            pincel.setColor(colores[i]);
            canvas.drawRect(dp(8), y - dp(12), dp(20), y, pincel);
            String etiqueta = ResumenEstudio.TIPOS[i] + ": " + numero(datos.porTipo[i]) + " h ("
                    + numero(datos.porTipo[i] / datos.total * 100) + "%)";
            texto(canvas, etiqueta, dp(28), y);
        }
    }

    static void aplicarMargenes(Activity activity, View root) {
        // La app aplica los márgenes una sola vez, también en Android 14.
        WindowCompat.setDecorFitsSystemWindows(activity.getWindow(), false);
        int izquierda = root.getPaddingLeft(), arriba = root.getPaddingTop();
        int derecha = root.getPaddingRight(), abajo = root.getPaddingBottom();
        ViewCompat.setOnApplyWindowInsetsListener(root, (v, insets) -> {
            Insets barras = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            Insets teclado = insets.getInsets(WindowInsetsCompat.Type.ime());
            v.setPadding(izquierda + barras.left, arriba + barras.top,
                    derecha + barras.right, abajo + Math.max(barras.bottom, teclado.bottom));

            if (navegacion != null) {
                // Al escribir dejamos más espacio al formulario; al cerrar el teclado vuelve la barra.
                boolean ocultar = insets.isVisible(WindowInsetsCompat.Type.ime()) || !navegacion.isEnabled();
                navegacion.setVisibility(ocultar ? View.GONE : View.VISIBLE);
            }
            // Los hijos ya están dentro del área útil y no deben repetir estos márgenes.
            return WindowInsetsCompat.CONSUMED;
        });
        ViewCompat.requestApplyInsets(root);
