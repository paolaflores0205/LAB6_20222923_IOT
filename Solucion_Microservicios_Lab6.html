SOLUCIÓN EXPLICADA

1. Qué cambió y por qué

La pantalla de Android ahora recibe los totales calculados por el backend. El código que agrupaba y sumaba horas se trasladó a EstadisticasService.calcular().

Firestore → Android → Reportes → Estadísticas
Estadísticas → Reportes → Android → Gráficos
Eureka permite que Reportes encuentre a Estadísticas.

Android sigue leyendo únicamente las sesiones del usuario autenticado mediante la ruta y las reglas existentes de Firestore. Convierte esos objetos a JSON y los envía junto al curso elegido. El backend no abre Firestore ni guarda sesiones.

Reportes añade un mensaje legible al resultado; Estadísticas concentra las validaciones, el filtro y las sumas. Esta separación es intencionalmente pequeña para practicar descubrimiento y Feign. En un sistema real habría que evaluar si justifica dos servicios independientes.

La sección Estadísticas de esta variante necesita el backend encendido. No calcula un resultado local si falla la red. El HTML Solucion_Lab6.html conserva la explicación de la versión original; este documento explica la nueva variante.

3. Cómo ejecutarlo ahora

Primero el backend

Abre una terminal en microservicios. Configura un JDK 17 o superior; se verificó con el JDK 21 integrado en Android Studio. Compila:

PowerShell
.\mvnw.cmd clean package

Después abre tres terminales en esa misma carpeta, una para cada comando. Conserva las tres abiertas:

PowerShell
# Terminal 1
.\mvnw.cmd -pl eureka-server spring-boot:run
# Terminal 2
.\mvnw.cmd -pl servicio-estadisticas spring-boot:run
# Terminal 3
.\mvnw.cmd -pl servicio-reportes spring-boot:run

También puedes abrir los tres archivos ejecutar-*.cmd. Abre http://localhost:8761/ y espera a ver SERVICIO-ESTADISTICAS y SERVICIO-REPORTES. La primera sincronización del registro puede tardar; un 503 inicial puede desaparecer después de actualizarse la caché.

Luego Android

  1. Ejecuta la app desde Android Studio en modo debug.
  2. Inicia sesión y abre Estadísticas.
  3. Escribe la dirección base de Reportes, sin añadir /reportes.
  4. Pulsa Consultar reporte. Selecciona un curso para volver a consultar.
DispositivoDirección que escribir
Emulador estándar de Androidhttp://10.0.2.2:8020
Teléfono físico en la misma redhttp://IP_LOCAL_DE_TU_PC:8020

En un teléfono, localhost sería el propio teléfono. Obtén la IPv4 de tu PC con ipconfig. Si Windows solicita permitir Java en la red privada, autoriza ese acceso para la prueba local.

La dirección se guarda en las preferencias de la pantalla. Esta variante no requiere cambiar tu app Firebase, las reglas existentes ni registrar nuevas huellas SHA por el backend. Si cambias de equipo de compilación Android, sigue aplicando la configuración de firma de Google que ya vimos.

La entrada contiene las sesiones y el filtro. Se usa POST porque enviamos una lista en el cuerpo JSON. La fecha se convierte en Android a yyyy-MM-dd para evitar depender del tipo Timestamp de Firebase.

JSON · entrada

  "curso": "IoT",
  "sesiones": [
    {
      "curso": "IoT",
      "fecha": "2026-11-17",
      "horasDedicadas": 1.5,
      "tipoActividad": "Teoría"
    },
    {
      "curso": "IoT",
      "fecha": "2026-11-18",
      "horasDedicadas": 2,
      "tipoActividad": "Laboratorio"
    },
    {
      "curso": "Redes",
      "fecha": "2026-10-12",
      "horasDedicadas": 3,
      "tipoActividad": "Práctica"
    }

Con el filtro IoT, se cuentan solo las dos primeras sesiones. Las de Redes siguen viajando, pero Estadísticas las excluye del resultado.

5. Eureka y la configuración de los servicios

Eureka escucha en 8761. Cada servicio anuncia su nombre y ubicación. El nombre que figura en @FeignClient debe coincidir con el spring.application.name de Estadísticas.

YAML
spring:
  application:
    name: lab6-eureka
server:
  port: 8761
eureka:
  client:
    register-with-eureka: false
    fetch-registry: false
management:
  endpoints:
    web:
      exposure:
        include: health

En el servidor independiente se deshabilitan registro y descarga del registro de otro servidor. En los dos clientes se configura la URL de Eureka:

YAML
spring:
  application:
    name: servicio-estadisticas
server:
  port: 8010
eureka:
  instance:
    hostname: localhost
    instance-id: ${spring.application.name}:${server.port}
  client:
    serviceUrl:
      defaultZone: ${EUREKA_URL:http://localhost:8761/eureka/}
management:
  endpoints:
    web:
      exposure:
        include: health

Los servicios usan hostname: localhost porque ambos backends corren en la misma PC. Un teléfono puede llamar al puerto 8020 de la PC, y Reportes puede seguir descubriendo Estadísticas en esa PC. Si distribuyes los backends en varias computadoras, tendrás que anunciar direcciones accesibles entre ellas.

6. El cálculo: un recorrido de la lista

Se inicializan las tres actividades en cero. Luego se recorre cada sesión, se validan sus campos, se comprueba el filtro y se acumulan sus horas.

Java
package com.example.lab6.estadisticas;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.web.server.ResponseStatusException;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;

@Service
public class EstadisticasService {
    public ResumenRespuesta calcular(SolicitudReporte solicitud) {
        if (solicitud == null || solicitud.getSesiones() == null) {
            throw error("Debes enviar una lista de sesiones.");
        }
        ResumenRespuesta resumen = new ResumenRespuesta();
        resumen.getHorasPorActividad().put("Teoría", 0.0);
        resumen.getHorasPorActividad().put("Práctica", 0.0);
        resumen.getHorasPorActividad().put("Laboratorio", 0.0);
        String filtro = solicitud.getCurso();
        if (filtro != null && filtro.isBlank()) filtro = null;
        for (SesionEntrada sesion : solicitud.getSesiones()) {
            // Se valida antes de usar los datos: nunca calculamos con horas inválidas.
            if (sesion == null || sesion.getCurso() == null || sesion.getCurso().isBlank()
                    || sesion.getCurso().length() > 100) throw error("Curso inválido.");
            Double horas = sesion.getHorasDedicadas();
            if (horas == null || !Double.isFinite(horas) || horas <= 0 || horas > 24) {
                throw error("Las horas deben ser mayores que 0 y como máximo 24.");
            }
            String tipo = sesion.getTipoActividad();
            if (!resumen.getHorasPorActividad().containsKey(tipo)) throw error("Actividad inválida.");
            LocalDate fecha;
            if (sesion.getFecha() == null) throw error("La fecha es obligatoria.");
            try { fecha = LocalDate.parse(sesion.getFecha()); }
            catch (DateTimeParseException e) {
                throw error("La fecha debe ser válida y tener formato yyyy-MM-dd.");
            }
            if (filtro != null && !filtro.equals(sesion.getCurso())) continue;
            String mes = fecha.toString().substring(0, 7);
            double acumuladoMes = resumen.getHorasPorMes().getOrDefault(mes, 0.0);
            resumen.getHorasPorMes().put(mes, acumuladoMes + horas);
            double acumuladoTipo = resumen.getHorasPorActividad().get(tipo);
            resumen.getHorasPorActividad().put(tipo, acumuladoTipo + horas);
            resumen.setCantidad(resumen.getCantidad() + 1);
            resumen.setTotalHoras(resumen.getTotalHoras() + horas);
        }
        return resumen;
    }
    private ResponseStatusException error(String mensaje) {
        return new ResponseStatusException(HttpStatus.BAD_REQUEST, mensaje);
    }
}

Las líneas importantes

  • Double permite valores como 1.5; int no serviría para conservarlos.
  • LocalDate.parse() comprueba que la fecha exista.
  • continue salta las sesiones que no pertenecen al curso seleccionado.
  • yyyy-MM distingue noviembre de 2025 de noviembre de 2026.
  • getOrDefault(mes, 0.0) empieza en cero cuando aparece un mes por primera vez.
  • acumulado + horas suma a cada grupo. La cantidad y el total se incrementan en el mismo recorrido.

No hay consultas SQL, recursión o lógica avanzada. Se usan una lista, dos mapas, validaciones y un bucle. Los datos inválidos se rechazan con 400; no se suman silenciosamente.

El controller solo recibe HTTP y delega ese cálculo:

Java
package com.example.lab6.estadisticas;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class EstadisticasController {
    private final EstadisticasService service;
    public EstadisticasController(EstadisticasService service) { this.service = service; }
    @PostMapping("/estadisticas")

        return service.calcular(solicitud);
    }
}

7. Reportes llama a Estadísticas con Feign

Esta interfaz es el contrato del cliente remoto. No implementa el cálculo ni contiene el puerto 8010.

Java
package com.example.lab6.reportes;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;

// Este nombre debe coincidir con spring.application.name del proveedor.
@FeignClient(name = "servicio-estadisticas")
public interface EstadisticasClient {
    @PostMapping("/estadisticas")
    ResumenRespuesta calcular(@RequestBody SolicitudReporte solicitud);
}

Spring crea el cliente a partir de @FeignClient. La aplicación Reportes habilita las interfaces con @EnableFeignClients y tiene las dependencias de Eureka, Feign y LoadBalancer. Cuando se llama a client.calcular(solicitud), la integración localiza una instancia y envía POST a su ruta /estadisticas.

Java
package com.example.lab6.reportes;
import feign.FeignException;
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.server.ResponseStatusException;
import java.util.Locale;

@RestController
public class ReporteController {
    private final EstadisticasClient client;
    public ReporteController(EstadisticasClient client) { this.client = client; }
    @PostMapping("/reportes")
    public ResumenRespuesta crear(@RequestBody SolicitudReporte solicitud) {
        try {
            ResumenRespuesta resumen = client.calcular(solicitud);
            // Reportes prepara el mensaje; todas las sumas las hace Estadísticas.
            String curso = solicitud.getCurso();
            String alcance = curso == null || curso.isBlank() ? "Todos los cursos" : curso;
            resumen.setMensaje(String.format(new Locale("es", "PE"),
                    "%s: %d sesiones · %.2f horas", alcance, resumen.getCantidad(), resumen.getTotalHoras()));
            return resumen;
        } catch (FeignException.BadRequest e) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "Revisa los datos de las sesiones.");
        } catch (FeignException e) {
            throw new ResponseStatusException(HttpStatus.SERVICE_UNAVAILABLE,
                    "Estadísticas no está disponible. Revisa el servicio y su registro en Eureka.");
        }
    }
}

Reportes agrega un mensaje y conserva las cifras recibidas. Si Estadísticas rechaza datos, devuelve 400. Si no logra contactarlo, responde 503. No hay fallback que calcule en Reportes ni respuesta ficticia cuando el proveedor está caído.

La inyección por constructor significa que Spring entrega la dependencia al crear el controller. Solo hay un constructor, por lo que no hace falta escribir @Autowired.

8. Android hace HTTP fuera del hilo de pantalla

ReporteApi usa HttpURLConnection, disponible en Android. No añadimos Retrofit ni otra dependencia. Convierte cada sesión a JSON, envía POST y transforma la respuesta en los datos que ya entienden los gráficos.

Ver ReporteApi.java completo
Java
package com.example.lab6;
import org.json.JSONArray;
import org.json.JSONException;
import org.json.JSONObject;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;
import java.text.SimpleDateFormat;
import java.util.Iterator;
import java.util.List;
import java.util.Locale;

// Solo transforma JSON y realiza HTTP. Debe llamarse desde un hilo de trabajo.
public class ReporteApi {
    public static class Resultado {
        public final ResumenEstudio resumen;
        public final String mensaje;
        Resultado(ResumenEstudio resumen, String mensaje) {
            this.resumen = resumen; this.mensaje = mensaje;
        }
    }
    public static Resultado consultar(String servidor, List<Sesion> sesiones, String curso)
            throws IOException, JSONException {
        String base = servidor.trim().replaceAll("/+$", "");
        URL url = new URL(base + "/reportes");
        if ((!url.getProtocol().equals("http") && !url.getProtocol().equals("https")) || url.getHost().isEmpty()) {
            throw new IOException("La dirección debe comenzar con http:// o https://.");
        }
        JSONArray lista = new JSONArray();
        SimpleDateFormat fecha = new SimpleDateFormat("yyyy-MM-dd", Locale.ROOT);
        for (Sesion sesion : sesiones) {
            if (sesion.getFecha() == null) throw new IOException("Hay una sesión sin fecha válida.");
            JSONObject dato = new JSONObject();
            dato.put("curso", sesion.getCurso());
            dato.put("fecha", fecha.format(sesion.getFecha()));
            dato.put("horasDedicadas", sesion.getHorasDedicadas());
            dato.put("tipoActividad", sesion.getTipoActividad());
            lista.put(dato);
        }
        JSONObject solicitud = new JSONObject();
        solicitud.put("curso", curso == null ? JSONObject.NULL : curso);
        solicitud.put("sesiones", lista);
        HttpURLConnection conexion = (HttpURLConnection) url.openConnection();
        try {
            conexion.setRequestMethod("POST");
            conexion.setConnectTimeout(4000);
            conexion.setReadTimeout(10000);
            conexion.setRequestProperty("Content-Type", "application/json; charset=UTF-8");
            conexion.setRequestProperty("Accept", "application/json");
            conexion.setDoOutput(true);
            byte[] datos = solicitud.toString().getBytes(StandardCharsets.UTF_8);
            conexion.setFixedLengthStreamingMode(datos.length);
            try (OutputStream salida = conexion.getOutputStream()) { salida.write(datos); }
            int estado = conexion.getResponseCode();
            if (estado == 400) throw new IOException("HTTP 400: revisa los datos de las sesiones.");
            if (estado == 503) throw new IOException("HTTP 503: Estadísticas no está disponible. Revisa su registro en Eureka.");
            if (estado != 200) throw new IOException("El servicio de reportes respondió HTTP " + estado + ".");
            String texto;
            try (InputStream entrada = conexion.getInputStream()) {
                texto = new String(entrada.readAllBytes(), StandardCharsets.UTF_8);
            }
            JSONObject respuesta = new JSONObject(texto);
            ResumenEstudio resumen = new ResumenEstudio();
            resumen.cantidad = respuesta.getInt("cantidad");
            resumen.total = respuesta.getDouble("totalHoras");
            JSONObject meses = respuesta.getJSONObject("horasPorMes");
            Iterator<String> claves = meses.keys();
            while (claves.hasNext()) {
                String mes = claves.next();
                resumen.porMes.put(mes, meses.getDouble(mes));
            }
            JSONObject actividades = respuesta.getJSONObject("horasPorActividad");
            for (int i = 0; i < ResumenEstudio.TIPOS.length; i++) {
                resumen.porTipo[i] = actividades.getDouble(ResumenEstudio.TIPOS[i]);
            }
            return new Resultado(resumen, respuesta.getString("mensaje"));
        } finally { conexion.disconnect(); }
    }
}

Los pasos son: construir JSON → abrir conexión → escribir cuerpo → comprobar estado → leer respuesta → cerrar conexión. Se configuran tiempos de espera para que una caída no deje la app esperando indefinidamente.

EstadisticasActivity utiliza un ExecutorService con un hilo. Así la conexión no bloquea el teclado, los botones o el dibujo de la app. Los cambios de pantalla se hacen con runOnUiThread().

Ver EstadisticasActivity.java completo
Java
package com.example.lab6;
import android.os.Bundle;
import android.view.View;
import android.widget.AdapterView;
import android.widget.ArrayAdapter;
import com.example.lab6.databinding.ActivityEstadisticasBinding;
import com.google.firebase.firestore.DocumentSnapshot;
import com.google.firebase.firestore.ListenerRegistration;
import java.util.ArrayList;
import java.util.TreeSet;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;

public class EstadisticasActivity extends PantallaBase {
    private ActivityEstadisticasBinding binding;
    private final ArrayList<Sesion> sesiones = new ArrayList<>();
    private final ArrayList<String> cursos = new ArrayList<>();
    private final ExecutorService executor = Executors.newSingleThreadExecutor();
    private ListenerRegistration escucha;
    private Future<?> peticion;
    private boolean activa, datosCargados;
    private int numeroPeticion;
    @Override protected void onCreate(Bundle state) {
        super.onCreate(state);
        binding = ActivityEstadisticasBinding.inflate(getLayoutInflater());
        setContentView(binding.getRoot());
        aplicarMargenes(this, binding.getRoot());
        prepararNavegacion(binding.navegacion, R.id.navEstadisticas);
        String servidor = getPreferences(MODE_PRIVATE).getString("servidor", "http://10.0.2.2:8020");
        binding.etServidor.setText(servidor);
        binding.btnActualizar.setOnClickListener(v -> consultarReporte());
        binding.spCurso.setOnItemSelectedListener(new AdapterView.OnItemSelectedListener() {
            @Override public void onItemSelected(AdapterView<?> parent, View view, int position, long id) {
                consultarReporte();
            }
            @Override public void onNothingSelected(AdapterView<?> parent) { }
        });
    }
    @Override protected void onStart() {
        super.onStart();
        if (!comprobarUsuario()) return;
        activa = true; datosCargados = false;
        binding.btnActualizar.setEnabled(true);
        mostrarEstado("Leyendo tus sesiones de Firestore…");
        escucha = misSesiones().addSnapshotListener((datos, error) -> {
            if (error != null) {
                datosCargados = false; numeroPeticion++;
                binding.btnActualizar.setEnabled(true);
                mostrarEstado("No se pudieron leer las sesiones. Revisa la conexión y los permisos de Firestore.");
                return;
            }
            String anterior = binding.spCurso.getSelectedItemPosition() > 0 ? (String) binding.spCurso.getSelectedItem() : null;
            sesiones.clear();
            TreeSet<String> nombres = new TreeSet<>();
            if (datos != null) for (DocumentSnapshot documento : datos.getDocuments()) {
                Sesion sesion = documento.toObject(Sesion.class);
                if (sesion != null && sesion.getCurso() != null) {
                    sesiones.add(sesion); nombres.add(sesion.getCurso());
                }
            }
            cursos.clear(); cursos.add("Todos los cursos"); cursos.addAll(nombres);
            ArrayAdapter<String> adapter = new ArrayAdapter<>(this, android.R.layout.simple_spinner_item, cursos);
            adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item);
            binding.spCurso.setAdapter(adapter);
            int posicion = anterior == null ? 0 : cursos.indexOf(anterior);
            binding.spCurso.setSelection(Math.max(0, posicion));
            datosCargados = true;
            consultarReporte();
        });
    }
    private void consultarReporte() {
        if (!activa || !datosCargados) return;
        String servidor = binding.etServidor.getText().toString().trim();
        if (servidor.isEmpty()) { binding.etServidor.setError("Ingresa la dirección de Reportes"); return; }
        getPreferences(MODE_PRIVATE).edit().putString("servidor", servidor).apply();
        String curso = binding.spCurso.getSelectedItemPosition() > 0 ? (String) binding.spCurso.getSelectedItem() : null;
        ArrayList<Sesion> copia = new ArrayList<>(sesiones);
        int numero = ++numeroPeticion;
        if (peticion != null) peticion.cancel(true);
        binding.btnActualizar.setEnabled(false);
        mostrarEstado("Consultando el reporte…");
        // HTTP se ejecuta fuera del hilo de pantalla para no bloquear la app.
        peticion = executor.submit(() -> {
            try {
                ReporteApi.Resultado resultado = ReporteApi.consultar(servidor, copia, curso);
                runOnUiThread(() -> {
                    // Una respuesta anterior no debe reemplazar el filtro más reciente.
                    if (!activa || numero != numeroPeticion) return;
                    binding.btnActualizar.setEnabled(true);
                    binding.tvResumen.setText(resultado.resumen.cantidad == 0 ? "No hay sesiones para este filtro." : resultado.mensaje);
                    binding.graficoBarras.setVisibility(View.VISIBLE);
                    binding.graficoTorta.setVisibility(View.VISIBLE);
                    binding.graficoBarras.mostrar(resultado.resumen, false);
                    binding.graficoTorta.mostrar(resultado.resumen, true);
                });
            } catch (Exception e) {
                runOnUiThread(() -> {
                    if (!activa || numero != numeroPeticion) return;
                    binding.btnActualizar.setEnabled(true);
                    mostrarEstado("No se pudo obtener el reporte. Revisa la dirección y los tres servidores.\n" + e.getMessage());
                });
            }
        });
    }
    private void mostrarEstado(String mensaje) {
        binding.tvResumen.setText(mensaje);
        binding.graficoBarras.setVisibility(View.GONE);
        binding.graficoTorta.setVisibility(View.GONE);
    }
    @Override protected void onStop() {
        activa = false; numeroPeticion++;
        if (peticion != null) peticion.cancel(true);
        if (escucha != null) { escucha.remove(); escucha = null; }
        super.onStop();
    }
    @Override protected void onDestroy() { executor.shutdownNow(); super.onDestroy(); }
}

Evitar que un resultado antiguo reemplace un filtro nuevo

Si cambias rápidamente de IoT a Redes, una respuesta de IoT podría llegar después. Cada consulta recibe un número. La pantalla solo muestra el resultado si ese número coincide con el más reciente y la Activity sigue activa.

Actualización con Firestore

El listener conserva la lectura de sesiones propias. Cuando cambia la lista, se prepara una nueva petición. El filtro por curso viaja al backend: Android no filtra y suma otra vez los valores del reporte.

Java
package com.example.lab6.estadisticas;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.web.server.ResponseStatusException;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;

@Service
public class EstadisticasService {
    public ResumenRespuesta calcular(SolicitudReporte solicitud) {
        if (solicitud == null || solicitud.getSesiones() == null) {
            throw error("Debes enviar una lista de sesiones.");
        }
        ResumenRespuesta resumen = new ResumenRespuesta();
        resumen.getHorasPorActividad().put("Teoría", 0.0);
        resumen.getHorasPorActividad().put("Práctica", 0.0);
        resumen.getHorasPorActividad().put("Laboratorio", 0.0);
        String filtro = solicitud.getCurso();
        if (filtro != null && filtro.isBlank()) filtro = null;
        for (SesionEntrada sesion : solicitud.getSesiones()) {
            // Se valida antes de usar los datos: nunca calculamos con horas inválidas.
            if (sesion == null || sesion.getCurso() == null || sesion.getCurso().isBlank()
                    || sesion.getCurso().length() > 100) throw error("Curso inválido.");
            Double horas = sesion.getHorasDedicadas();
            if (horas == null || !Double.isFinite(horas) || horas <= 0 || horas > 24) {
                throw error("Las horas deben ser mayores que 0 y como máximo 24.");
            }
            String tipo = sesion.getTipoActividad();
            if (!resumen.getHorasPorActividad().containsKey(tipo)) throw error("Actividad inválida.");
            LocalDate fecha;
            if (sesion.getFecha() == null) throw error("La fecha es obligatoria.");
            try { fecha = LocalDate.parse(sesion.getFecha()); }
            catch (DateTimeParseException e) {
                throw error("La fecha debe ser válida y tener formato yyyy-MM-dd.");
            }
            if (filtro != null && !filtro.equals(sesion.getCurso())) continue;
            String mes = fecha.toString().substring(0, 7);
            double acumuladoMes = resumen.getHorasPorMes().getOrDefault(mes, 0.0);
            resumen.getHorasPorMes().put(mes, acumuladoMes + horas);
            double acumuladoTipo = resumen.getHorasPorActividad().get(tipo);
            resumen.getHorasPorActividad().put(tipo, acumuladoTipo + horas);
            resumen.setCantidad(resumen.getCantidad() + 1);
            resumen.setTotalHoras(resumen.getTotalHoras() + horas);
        }
        return resumen;
    }
    private ResponseStatusException error(String mensaje) {
        return new ResponseStatusException(HttpStatus.BAD_REQUEST, mensaje);
    }
}

package com.example.lab6.reportes;
import feign.FeignException;
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.server.ResponseStatusException;
import java.util.Locale;

@RestController
public class ReporteController {
    private final EstadisticasClient client;
    public ReporteController(EstadisticasClient client) { this.client = client; }
    @PostMapping("/reportes")
    public ResumenRespuesta crear(@RequestBody SolicitudReporte solicitud) {
        try {
            ResumenRespuesta resumen = client.calcular(solicitud);
            // Reportes prepara el mensaje; todas las sumas las hace Estadísticas.
            String curso = solicitud.getCurso();
            String alcance = curso == null || curso.isBlank() ? "Todos los cursos" : curso;
            resumen.setMensaje(String.format(new Locale("es", "PE"),
                    "%s: %d sesiones · %.2f horas", alcance, resumen.getCantidad(), resumen.getTotalHoras()));
            return resumen;
        } catch (FeignException.BadRequest e) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "Revisa los datos de las sesiones.");
        } catch (FeignException e) {
            throw new ResponseStatusException(HttpStatus.SERVICE_UNAVAILABLE,
                    "Estadísticas no está disponible. Revisa el servicio y su registro en Eureka.");
        }
    }
}

15. Cómo explicarlo en el laboratorio

“Android lee las sesiones de su usuario y las envía como JSON a Reportes. Reportes llama a Estadísticas con Feign usando su nombre registrado en Eureka. Estadísticas valida, filtra y suma. Reportes añade el mensaje y Android dibuja los resultados. Eureka proporciona ubicaciones; no procesa los datos de estudio.”

Para añadir otra estadística, empieza por EstadisticasService y el DTO de respuesta. Modifica Android solo si necesitas una nueva representación visual. Para cambiar la dirección de Reportes en tu red, usa el campo de la pantalla; no necesitas recompilar por ese cambio.
